The cast and the script

Seven voices supports a narrator plus every companion. A literal replacement of today’s script needs one: all current story text is third-person narration.

Production coverage is 36 story readings + 50 unique instruction readings. Character samples here are existing identity quotes for auditions, not added game dialogue. The narrator sample combines a sample setup with two current consequences.

Start with these existing voices

Listen for clear contrasts, natural pacing, and understandable words. Pip’s nervousness and Tumble’s laughter are the two performances most likely to need restraint. Try the narrator on a real puzzle instruction before production.

Optional custom directions if an audition misses

Pip: A light, nimble adult character voice for a small moth. Alert, earnest and quietly brave, with a tiny nervous pause before a dry joke. Clear natural diction, gentle warmth, no squeaking or exaggerated stammer.

Tumble: A warm, rounded adult character voice for a cheerful furry traveler. Buoyant, slightly rumbling, affectionate and matter-of-fact about silly things. Crisp diction and playful pauses; occasional soft chuckle, never constant laughter.

Use Voice Design only if listening reveals a mismatch. No voice cloning is needed.
